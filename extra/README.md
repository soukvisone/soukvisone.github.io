# extra/ — ชุดสคริปต์รุ่นก่อน (เก็บไว้เผื่อใช้)

โฟลเดอร์นี้ **ไม่ใช่ของหลัก** — ตัวหลักคือ `scripts/` ที่อยู่ข้างบน
ของใน `extra/` เก็บไว้เพราะมีสคริปต์บางตัวที่ `scripts/` ยังไม่มี (แยกตามหมวดครบกว่า)

```
extra/
├── ctf-toolkit/       รุ่น 1 — 32 สคริปต์ แยก 7 หมวด (forensics/malware/web/reverse/osint/crypto/misc)
└── ctf-toolkit-v2/    รุ่น 2 — เพิ่ม 6 สคริปต์เฉพาะทาง + ปรับ auto_decode/xor ให้ฉลาดขึ้น
```

## ใช้เมื่อไหร่

| ต้องการ | ใช้ |
|---|---|
| ไล่หา flag แบบเร็ว / สั่งงานเดียว | `scripts/` (run_pipeline, flag_hunt) |
| ต้องการสคริปต์แยกตามหมวดครบ ๆ | `extra/ctf-toolkit/` |
| เจอโจทย์แนว Vigenère / zip ในรูป / PHP ซ้อนชั้น / UPX | `extra/ctf-toolkit-v2/` |
| เอกสาร/เช็กลิสต์ | `docs/` |

## ข้อควรรู้

- ทั้งสองชุดแก้ที่ **ตัวแปรบรรทัดเดียว** ที่หัวไฟล์ (`FILE=`, `URL=`, `DATA=`)
- แต่ละชุดมี `setup.sh` ของตัวเอง (ตรวจ tool ที่ขาด) — หรือใช้ `install.sh` ที่ root ก็พอ
- `ctf-toolkit-v2` มีสคริปต์ที่ **ผูกกับโจทย์บางข้อโดยเฉพาะ** เช่น `solve_plato_jigsaw.py`
  (สมมติว่าจิ๊กซอว์ 4×3 และมีแท็ก `>>>>> ... <<<<<`) — ถ้าโจทย์เปลี่ยนรูปแบบต้องแก้โค้ดข้างใน
- สคริปต์ใน `extra/` ยังไม่ได้ผ่านการทดสอบเท่าระดับ `scripts/` — ใช้เป็นจุดเริ่มต้นแล้วปรับได้

## ตัวอย่าง

```bash
# ชุดรุ่น 1: ตรวจไฟล์แล้วเรียกสคริปต์ที่เหมาะสมให้
bash extra/ctf-toolkit/triage.sh challenge.bin

# ชุดรุ่น 2: แกะ PHP ที่ห่อหลายชั้น
python3 extra/ctf-toolkit-v2/reverse/matryoshka.py

# ชุดรุ่น 2: หา flag แบบ 3 ชั้น (จับแม้ flag ที่ยังเข้ารหัสอยู่)
python3 extra/ctf-toolkit-v2/misc/flagscan.py .
```
