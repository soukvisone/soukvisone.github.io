================================================================
 OSINT — เช็กลิสต์ไล่หาข้อมูล (ภาษาไทย อ่านง่าย)
================================================================
ใช้เมื่อโจทย์ให้ "ชื่อคน / ชื่อผู้ใช้ / โดเมน / รูป / อีเมล" มา แล้วถามหา
ข้อมูลที่เชื่อมโยงกัน (บางทีคำตอบคือแฟล็ก)

กฎเหล็ก: ทำเฉพาะเป้าหมายที่โจทย์กำหนด (มักเป็น persona สมมติ)
          ห้ามส่องคนจริง บัญชีจริง หรือเว็บที่ไม่ได้อยู่ในขอบเขต

----------------------------------------------------------------
1) ได้ "ชื่อผู้ใช้ (username)" มา
----------------------------------------------------------------
[ ] ลองค้นในเสิร์ชเอนจินด้วย "ชื่อผู้ใช้" + คำที่เกี่ยวข้อง
[ ] เว็บเช็กชื่อผู้ใช้ซ้ำหลาย-platform (ทำในเบราว์เซอร์เอง เช่น whatsmyname)
[ ] ตรวจ GitHub / GitLab:  มักมีอีเมลใน commit
      -> ดู commit author email ด้วย:  git log --format='%ae %an'
[ ] ตรวจ pastebin / forum เก่า ๆ ด้วยชื่อเดียวกัน
[ ] ดูว่าใช้ชื่อเดิมในอีเมลด้วยไหม (username@domain)

----------------------------------------------------------------
2) ได้ "โดเมน / เว็บไซต์" มา
----------------------------------------------------------------
[ ] whois domain.com                -> เจ้าของ, วันที่จด, nameserver
[ ] dig domain.com ANY              -> DNS record ทั้งหมด
[ ] dig +short domain.com MX        -> เมลเซิร์ฟเวอร์
[ ] dig +short txt domain.com       -> TXT record (บางทีมีแฟล็ก!)
[ ] host -t ns domain.com
[ ] ดู certificate transparency (ค้นในเบราว์เซอร์: crt.sh) -> เจอ subdomain
[ ] ลอง subdomain ที่พบบ่อย:  www, mail, dev, staging, admin, api, vpn, test
[ ] ดู robots.txt และ /.well-known/security.txt

----------------------------------------------------------------
3) ได้ "อีเมล" มา
----------------------------------------------------------------
[ ] ตรวจรูปแบบ: ชื่อ.นามสกุล@บริษัท
[ ] ดูว่าเคยรั่วใน breach ไหม (-haveibeenpwned ผ่านเบราว์เซอร์เอง)
[ ] ดู gravatar: md5 ของอีเมล -> https://gravatar.com/avatar/<md5>
      คำนวณในเครื่อง:  echo -n "user@example.com" | md5sum
[ ] ดูว่าเป็นอีเมลเดียวกันกับ GitHub commit ไหม

----------------------------------------------------------------
4) ได้ "รูป" มา
----------------------------------------------------------------
[ ] exiftool photo.jpg              -> GPS, กล้อง, เวลา
[ ] ใช้ osint/image_osint.sh         -> แปลงพิกัดเป็นลิงก์แผนที่
[ ] ค้นย้อนกลับด้วยภาพ (Google Lens / Yandex / TinEye) — ทำในเบราว์เซอร์
[ ] ดูรายละเอียดในภาพ: ป้ายถนน, ภาษา, ตราประทับเวลา, สภาพอากาศ
[ ] ถ้าเป็นภาพหน้าจอ ให้ดูแถบงาน/ชื่อผู้ใช้/เวลาในระบบ

----------------------------------------------------------------
5) ได้ "ชื่อคน" มา
----------------------------------------------------------------
[ ] ค้นชื่อ + ประเทศ/องค์กร
[ ] ดู LinkedIn/Facebook สาธารณะ (แค่ดู ไม่ติดต่อ)
[ ] ดูชื่อในเอกสาร PDF ที่ค้นเจอ (metadata มักมีชื่อผู้สร้าง)
[ ] ลองแปลงชื่อเป็น username แบบต่าง ๆ: name.surname, nsurname, surname+ปี

----------------------------------------------------------------
6) ข้อมูลที่มักเป็นคำตอบของโจทย์ OSINT
----------------------------------------------------------------
- ชื่อเต็มของเจ้าของโดเมน
- วันที่จดโดเมน / วันเกิด
- พิกัดสถานที่ในรูป
- อีเมลที่ซ่อนใน metadata หรือ commit
- ชื่อ Wi-Fi / SSID ในภาพถ่ายหน้าจอ
- เวลาที่โพสต์ (timezone อาจเป็นเบาะแส)

----------------------------------------------------------------
7) คำสั่งในเครื่องที่ใช้บ่อย (ทั้งหมดทำงานแบบ offline/local)
----------------------------------------------------------------
  whois domain.com
  dig domain.com ANY
  dig +short TXT domain.com
  host -t mx domain.com
  exiftool -a -u -g1 photo.jpg
  echo -n "a@b.com" | md5sum            # สำหรับ gravatar
  curl -s https://domain.com/robots.txt
