================================================================
 GDB / Pwndbg — คำสั่งที่ใช้บ่อยที่สุด (อธิบายเป็นภาษาไทย)
================================================================
วิธีเปิด:  gdb ./challenge
ถ้าติดตั้ง pwndbg หรือ gef ไว้ จะเห็นหน้าจอสวยขึ้นและมีคำสั่งเสริม

----------------------------------------------------------------
1) ก่อนเริ่ม — คำสั่งพื้นฐาน
----------------------------------------------------------------
  file ./challenge        โหลดโปรแกรม
  set disassembly-flavor intel    อ่าน assembly แบบ intel (อ่านง่ายกว่า)
  run                     เริ่มรันโปรแกรม
  run < input.txt         รันโดยป้อนข้อมูลจากไฟล์
  run AAAA                รันโดยใส่อาร์กิวเมนต์
  quit                    ออก

----------------------------------------------------------------
2) ตั้งจุดหยุด (breakpoint) — หัวใจของการ reverse
----------------------------------------------------------------
  break main              หยุดที่ฟังก์ชัน main
  break *0x401234         หยุดที่ตำแหน่ง address ที่ระบุ
  break flag              หยุดที่ฟังก์ชันชื่อ flag (ถ้ามี symbol)
  info breakpoints        ดูกี่จุด หยุดไว้ตรงไหน
  delete 1                ลบจุดหยุดที่ 1
  disable 1               ปิดจุดหยุดที่ 1 ชั่วคราว
  enable 1                เปิดคืน

  (คำย่อที่ใช้ได้: b = break, c = continue, n = next, s = step, i = info)

----------------------------------------------------------------
3) เดินทีละขั้น
----------------------------------------------------------------
  continue (c)            ไปต่อจนเจอจุดหยุดตัวถัดไป
  next (n)                ทำบรรทัดนี้ให้จบ (ไม่เข้าไปในฟังก์ชัน)
  step (s)                เข้าไปข้างในฟังก์ชันที่เรียก
  nexti (ni)              ทำ 1 คำสั่ง assembly
  stepi (si)              เข้าไป 1 คำสั่ง assembly
  finish                  ทำฟังก์ชันนี้ให้จบแล้วหยุด
  until                   ออกจากการวนซ้ำ (loop) ปัจจุบัน

----------------------------------------------------------------
4) ดูค่า / หน่วยความจำ
----------------------------------------------------------------
  info registers          ดูค่า register ทั้งหมด (rax, rdi, rsi...)
  p $rax                  พิมพ์ค่า register rax
  p/d $rax                พิมพ์เป็นเลขฐานสิบ
  p $rip                  ตำแหน่งคำสั่งถัดไป
  x/s $rdi                ดูข้อความที่ rdi ชี้อยู่ (สำคัญมาก! มักเป็นรหัสผ่าน)
  x/20x $rsp              ดู stack 20 ค่าในรูปแบบ hex
  x/10i $rip              ดู 10 คำสั่ง assembly ข้างหน้าจุดที่หยุดอยู่
  info frame              ดูข้อมูล frame ปัจจุบัน
  bt                      ดู call stack (ใครเรียกใคร)

  ตัวอักษรหลัง x/ บอกชนิดข้อมูล:
     x = hex, d = decimal, s = string, i = instruction, c = char

----------------------------------------------------------------
5) แก้ค่าตอนรัน (ใช้ข้ามการตรวจรหัสผ่าน)
----------------------------------------------------------------
  set $rax = 1            เปลี่ยนค่า register
  set {int}0x601050 = 1   เขียนค่าลงหน่วยความจำที่ address นั้น
  jump *0x401200          กระโดดข้ามไปตำแหน่งที่ต้องการ (ข้ามการเช็ก)
  return                  บังคับให้ฟังก์ชันปัจจุบันคืนค่าออกไปเลย

  ตัวอย่างคลาสสิก: โปรแกรมตรวจรหัสแล้วถ้าไม่ตรงจะ exit
     break *0x4011a0  (ตำแหน่งหลัง call strcmp)
     set $rax = 0     (ให้ค่าเทียบเป็น "เท่ากัน")
     continue

----------------------------------------------------------------
6) ค้นหาในหน่วยความจำ (หาแฟล็กที่ถูกประกอบตอนรัน)
----------------------------------------------------------------
  find 0x400000, 0x500000, "CSG_FLAG"        หาในหน่วยความจำ
  find $rsp, $rsp+0x1000, "flag"
  grep "CSG"                                (pwndbg) ค้นทั้ง memory map
  search-pattern "CSG_FLAG"                 (gef)
  vmmap                                     (pwndbg/gef) ดู memory map

----------------------------------------------------------------
7) คำสั่งเสริมของ pwndbg / gef (ถ้าติดตั้งไว้)
----------------------------------------------------------------
  context                 แสดงหน้าจอสรุป (register, stack, code, backtrace)
  stack 20                ดู stack 20 บรรทัด
  hexdump $rsp 64         ดัมป์หน่วยความจำ
  telescope $rsp 20       (pwndbg) ดู stack แบบอ่านง่าย
  heap / bins             ดู heap (สำหรับโจทย์ pwn)
  checksec                ดูการป้องกันของไฟล์
  got / plt               ดูตาราง GOT/PLT

----------------------------------------------------------------
8) ทางลัดเมื่อไม่แน่ใจ: 3 อย่างที่ควรลองก่อน
----------------------------------------------------------------
  1) b main -> run -> ไล่ดูว่าเรียก strcmp/strlen ที่ไหน (ใช้ ni ไปเรื่อย ๆ)
  2) หยุดที่ strcmp แล้วดู x/s $rdi กับ x/s $rsi -> มักเห็นรหัสผ่านตรง ๆ
  3) ใช้ ltrace ก่อนก็ได้ (ง่ายกว่า): ltrace ./challenge

----------------------------------------------------------------
9) ตัวอย่างเซสชันจริง (คัดลอกทีละบรรทัดได้)
----------------------------------------------------------------
  gdb -q ./challenge
  (gdb) set disassembly-flavor intel
  (gdb) b main
  (gdb) run
  (gdb) ni                  <-- กดต่อไปเรื่อย ๆ จนเจอ call strcmp
  (gdb) x/s $rdi            <-- ข้อความที่ผู้ใช้พิมพ์
  (gdb) x/s $rsi            <-- ข้อความที่โปรแกรมคาดหวัง = รหัสผ่าน
  (gdb) continue
  (gdb) quit

----------------------------------------------------------------
10) บันทึกหน้าจอไว้ทำรายงาน
----------------------------------------------------------------
  set logging on            เริ่มบันทึก
  set logging file gdb.txt  ตั้งชื่อไฟล์
  set logging off           หยุดบันทึก
